## 🎯 Quick Deploy (10 minutes)

### 1. MongoDB Setup
```
1. Go to mongodb.com/cloud/atlas
2. Create FREE cluster
3. Create user: fintask / <strong-password>
4. Network: Add IP 0.0.0.0/0
5. Get connection string
```

### 2. Push to GitHub
```bash
git add .
git commit -m "Deploy to Render"
git push origin main
```

### 3. Deploy on Render
```
1. Go to dashboard.render.com
2. New + → Web Service
3. Connect GitHub repo
4. Render auto-detects render.yaml
5. Add environment variables:
   - MONGODB_URI (from step 1)
   - JWT_SECRET (click Generate)
6. Click "Create Web Service"
7. Wait 5-10 minutes
8. Done! 🎉
```

## 🔐 Environment Variables

Required variables for Render:

```env
NODE_ENV=production
PORT=10000
MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/fintask
JWT_SECRET=<auto-generated-by-render>
```

Optional variables:

```env
TELEGRAM_BOT_TOKEN=<your-bot-token>
TELEGRAM_CHAT_ID=<your-chat-id>
ALLOWED_ORIGINS=https://your-app.onrender.com
```

## 🐛 Troubleshooting

**Build fails:**
- Check Render logs
- Verify package.json scripts
- Ensure pnpm is available

**Database error:**
- Verify MONGODB_URI
- Check IP whitelist (0.0.0.0/0)
- Test connection string

**App crashes:**
- Check environment variables
- Review Render logs
- Verify PORT=10000

**502 Gateway:**
- Wait 2-3 minutes (starting)
- Check health endpoint: /api/ping
- Verify start command
